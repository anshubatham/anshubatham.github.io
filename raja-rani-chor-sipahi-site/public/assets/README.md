# Image assets

The uploaded images were not available in the workspace when this project was generated. Copy them into these exact locations before deploying:

* `ic_launcher-playstore.png` → `public/assets/logo.png`
* the ten supplied WhatsApp gameplay JPEG files → `public/assets/screenshots/screenshot-01.jpeg` through `screenshot-10.jpeg`

Keep the screenshots in the intended display order. The website will automatically use them without further edits.

For best performance, optionally export copies as WebP and update the image references in `public/index.html`.
